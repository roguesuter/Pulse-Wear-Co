# Pulse Wear — Website

`index.html` is the complete, self-contained company site: HTML, CSS, JavaScript and the Instrument Serif + Inter fonts embedded in one file. There is no build step, no external asset, and no backend.

## Preview

Double-click `index.html`, or open it in any modern browser.

## Deploy

Upload `index.html` to any static host — Netlify, Vercel, GitHub Pages, Cloudflare Pages, cPanel, S3, or a plain web server. Keep the file name `index.html` so it loads at the root URL.

## Contact form

The form opens the visitor's email app and addresses the message to `suteradrian8@gmail.com`, with `iamkipchirchir@gmail.com` copied. Nothing is stored or sent by the site itself.

## Notes

- Fonts and all visuals are embedded. The page works offline and makes no third-party requests.
- The CTO's LinkedIn profile is the only external link.
